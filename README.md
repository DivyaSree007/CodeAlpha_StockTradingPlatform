# CodeAlpha Stock Trading Platform

## Project Description

This is a Java-based Stock Trading Platform developed as part of the CodeAlpha Java Programming Internship.

The project simulates a basic stock trading environment where users can view market data, buy and sell stocks, and track their portfolio.

## Features

- Display stock market data
- Buy stocks
- Sell stocks
- Track user balance
- View portfolio
- Check available shares
- Prevent buying when balance is insufficient
- Prevent selling more shares than owned

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Java Scanner
- Git & GitHub
